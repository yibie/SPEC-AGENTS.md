# Run Protocol

Run from the repository root:

```bash
python3 research/experiments/project-knowledge-routing-pilot/run_pilot.py
```

The runner uses only the Python standard library, creates all implementation
fixtures under a temporary directory, and removes them on exit. It does not
modify repository files.

## Controlled sequence

1. Validate the required metadata and source Evidence on the Protocol,
   Runbook, and unrelated Lesson.
2. Measure default context versus the two intent-routed records.
3. In a temporary Git repository, apply the same harmless shell comment in
   both arms.
4. Run the control syntax check.
5. Run treatment syntax, whitespace, repeated installer smoke, and
   source-repository refusal checks.
6. Confirm that shell intent selects the Protocol and Runbook while browser
   form intent selects only the DOM Lesson.
7. Report the context cost, checks, limits, and next permitted action.

A valid result requires all treatment checks to pass and must distinguish
routing evidence from claims about Agent behavior.

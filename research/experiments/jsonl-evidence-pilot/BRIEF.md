# JSONL Evidence Ledger Pilot

## Question

Does JSONL make dynamic evidence easier to append, merge, revise, and read
selectively than an equivalent Markdown ledger, without making review opaque?

## Hypothesis

JSONL will be useful for dynamic, record-shaped evidence with stable IDs and
references. Markdown will remain better for the stable semantic model and
workflow instructions. This pilot should test that boundary rather than
replace the current documents.

## Scope

- two independent Agent JSONL streams;
- one unrelated phase record;
- one later record that supersedes an earlier claim;
- one equivalent Markdown fixture;
- a Python-standard-library-only runner.

## Non-goals

No production file is renamed, no current skill is changed, and no JSONL
schema is promoted to the project model from this run alone.

# Task 模板（BDD 单行格式）

## 格式规范

```
taskNNN [状态] 场景:<一句话描述> | Given:<前置条件> | When:<触发动作> | Then:<期望结果> | 验证:<测试方式>
```

## 字段说明

| 字段 | 必填 | 说明 |
|-----|------|------|
| `场景:` | ✓ | 用户视角的一句话描述，回答"谁在什么情况下做什么" |
| `Given:` | ✓ | 前置状态/数据，多个条件用 `+` 连接 |
| `When:` | ✓ | 用户操作、触发事件或系统动作 |
| `Then:` | ✓ | 可观察的结果/反馈，多个结果用 `+` 连接 |
| `验证:` | ✓ | 验证方式：手动测试/单元测试/UI测试/截图对比等 |

## 可选追加字段

放在行尾，用 `|` 分隔：

- `| 备注:<说明>` — 额外说明或注意事项
- `| 优先级:P0/P1/P2` — 任务优先级
- `| 依赖:taskNNN` — 依赖的其他任务

## 完整示例

```markdown
# Task List - Phase: <purpose>-<YYYYMMDD>

task001 [ ] 场景:用户通过快捷键将当前窗口置顶 | Given:用户正在使用某应用窗口 | When:按下 Cmd+Ctrl+T | Then:窗口保持在最前端+菜单栏显示置顶指示器 | 验证:手动测试+截图对比
task002 [ ] 场景:用户取消窗口置顶 | Given:窗口已处于置顶状态 | When:再次按下 Cmd+Ctrl+T | Then:窗口恢复正常层级+指示器消失 | 验证:手动测试
task003 [ ] 场景:重启后恢复置顶状态 | Given:用户之前将窗口A置顶并退出应用 | When:重新启动应用 | Then:窗口A自动恢复置顶状态 | 验证:单元测试(状态持久化) | 依赖:task001
task004 [ ] 场景:快捷键冲突检测 | Given:用户设置了已被系统占用的快捷键 | When:尝试保存设置 | Then:弹出冲突提示+建议替代组合 | 验证:UI测试截图对比 | 优先级:P1
task005 [x] 场景:多显示器环境下置顶 | Given:窗口位于副屏幕 | When:执行置顶快捷键 | Then:窗口在对应屏幕保持最前 | 验证:手动测试(双屏环境) | 备注:已验证通过
```

## 状态说明

- `[ ]` — 待完成
- `[x]` — 已完成
- `[-]` — 已取消/废弃（可选）

## 快速上手

复制下面这行作为你的第一个任务：

```markdown
task001 [ ] 场景: | Given: | When: | Then: | 验证:
```
